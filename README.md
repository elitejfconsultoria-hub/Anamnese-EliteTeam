# Anamnese EliteTeam

Página da anamnese online da EliteTeam Consultoria Premium.

- `index.html` é gerado pelo projeto da anamnese (`build.py`); não editar à mão.
- As respostas não ficam neste repositório: o formulário envia para o Google Apps Script da consultoria, que grava na planilha "EliteTeam - Anamneses" e salva as fotos no Google Drive.
